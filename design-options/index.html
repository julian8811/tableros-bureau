Opciones de rediseño del tablero

Cuatro direcciones con paleta Colmayor V7 y Montserrat. Las gráficas ya llevan ejes, valores, leyenda, callouts y acentos luminosos para que se lean rápido y se vean más “futuras”. Abre cada una a pantalla completa y elige A–D.

Opción A

Institucional claro

Fondo claro, barra navy + franja oro. Ideal para presentaciones a dirección y alianzas.

  • Superficies blancas / gris frío; tipografía institucional
  • Tabs con color de tablero (naranja / oro / teal)
  • Serie con comparación año vs año + pico etiquetado
  • Donut con % central y barras con cifra a la derecha
